# 第一天
第一天早上5点半出发， 打车去深圳湾口岸。 过关之后，可以直接搭公交车去香港机场。
落地之后，坐地铁到了中目黑，第一天晚上就去了涩谷。

## 感受
### 香港
香港方面：香港的公交站设计十分特别。站台比较长，会分成几个小段，各个小段就代表哪辆车会在这里停留
```
----------------------------------
| B3X |    A6  A7     |   B4   |
----------------------------------
```
当B4车到站台后，它就会停留在B4这个点上，A6/A7到了之后，就会停留在对应的位置。这个跟深圳公交站很不一样，深圳公交站台是这样子的。
```
----------------------------------
｜      公交站台（M403，M200。。）  ｜
----------------------------------
```
只要有车过来，那么就会在这个公交站台前一点的地方停留，不管是什么车。如果车次太多，那么可能会多开辟一个站台。

到了香港之后，明显感觉到当地的人基本只说粤语或者英语了。

### 东京
刚来到成田机场，出站后，第一个难点就在于怎么搭车去中目黑。一时没了主意，就去问工作人员。

工作人员十分热情，用日语详细跟我解释了下要去哪个站点下车，然后在那里转线，是的我绝大部分听不懂。但还是能知道要去 nihongbashi（日本桥）站，行，出发。

在地铁上仔细看了路线图，东京的地铁路线确实是很复杂。后面查了地图，发现应该要去银座（TODO,补充）站，但是这辆车会中间会越过好几个站，不到银座，所以我们在日本桥下了车，然后因为不熟悉情况，又找工作人员认了下，工作人员让我们还是到这个站台上车：nihongbashi，no。银座，yes。

到了朋友住的屋子，屋子布局也十分特别，入门有一个玄关，用来换鞋的地方。进门右手边是厕所，洗脸，洗澡，上厕所3地分离。然后再往前走右手边是一个柜子，放生活用品。然后进来是像厨房客厅一体的地方，再里面有个用榻榻米做的房间（这个更像是中国的客厅）。进这个客厅要拖鞋。

                    ｜                  ｜

   阳台              ｜   阳台            ｜   隔壁屋子阳台

在阳台之间有一道门，专门有一个警示，邻居在紧急情况下可以破这个门，这里是逃生的地方，请不要堆放物品。我感觉东京公寓对安全这一块做的十分好，一方面日本邻里之间十分注重各自的隐私，没有情况下不会打扰。但另外一个方面也为极端情况做了考量。让他们在紧急情况下可以避难逃生。所以如果真的是邻居破门了，我们有必要去帮助他们。

到了涩谷，很热闹，那个人行道4个红绿灯都变绿了之后，特别壮观，专门有很多人在附近建筑物的二楼去拍这个景色。涩谷也很干净。
专门有一个吸烟区，里面超多人吸烟。去忠犬八公的雕像拍了张照。

乌鸦很多。

学了日语：日本桥 (nihong bashi)

# 第二天
第二天早上9点半出发，前往横滨。在横滨逛了横滨美术馆，地标塔（地标塔上面扭了自由女神蛋，看了横滨全景），红砖仓库，然后搭车去了中华街，中华学校，外国人公墓。然后在山下公园坐了很久，然后返程吃了拉面。逛了日本的超市，感受到了他们的物价。

地标塔上面还可以看到东京。还有横滨全景，十分漂亮。印象最深的就是很多高楼大厦上都有停机坪。

红砖产（TODO：补充历史）里面买了个地球仪，准备带回去送给女儿。
红砖产外面有很多组织在做活动宣传，让你了解他们在做什么，有自卫队，让你感受一下他们背包的负重（20kg）。
有神奈川红十字会，会教你急救的知识，我就过去了，但是他说的是日语，不会英语，我听不懂。但是带我的老爷爷还是十分热情地来跟我介绍，教我遇到紧急情况要打119，怎么做心肺复苏，然后用AED，我跟着老爷爷教的大概做完后，他们给我发了红十字会的宣传单，然后用“正”的方式计数。
还有气象局等其他十分有趣的组织。我十分喜欢这个氛围。

中华街看到最多的竟然是看手相，而且有的店还很热闹。。。里面的吃的，好贵，比横滨其他地方都要贵。

在山下公园坐了很久很久，十分惬意。
拉面很咸，也很特别。
物价，很贵。

乌鸦很多。
