# 第一天
第一天早上5点半出发， 打车去深圳湾口岸。 过关之后，可以直接搭公交车去香港机场。
落地之后，坐地铁到了中目黑，第一天晚上就去了涩谷。

## 感受
### 香港
香港方面：香港的公交站设计十分特别。站台比较长，会分成几个小段，各个小段就代表哪辆车会在这里停留
```
----------------------------------
| B3X |    A6  A7     |   B4   |
----------------------------------
```
当B4车到站台后，它就会停留在B4这个点上，A6/A7到了之后，就会停留在对应的位置。这个跟深圳公交站很不一样，深圳公交站台是这样子的。
```
----------------------------------
｜      公交站台（M403，M200。。）  ｜
----------------------------------
```
只要有车过来，那么就会在这个公交站台前一点的地方停留，不管是什么车。如果车次太多，那么可能会多开辟一个站台。

到了香港之后，明显感觉到当地的人基本只说粤语或者英语了。

### 东京
刚来到成田机场，出站后，第一个难点就在于怎么搭车去中目黑。一时没了主意，就去问工作人员。

工作人员十分热情，用日语详细跟我解释了下要去哪个站点下车，然后在那里转线，是的我绝大部分听不懂。但还是能知道要去 nihongbashi（日本桥）站，行，出发。

在地铁上仔细看了路线图，东京的地铁路线确实是很复杂。后面查了地图，发现应该要去银座（ginza）站，但是这辆车会中间会越过好几个站，不到银座，所以我们在日本桥下了车，然后因为不熟悉情况，又找工作人员认了下，工作人员让我们还是到这个站台上车：nihongbashi，no。ginza，yes。

到了朋友住的屋子，屋子布局也十分特别，入门有一个玄关，用来换鞋的地方。进门右手边是厕所，洗脸，洗澡，上厕所3地分离。然后再往前走右手边是一个柜子，放生活用品。然后进来是像厨房客厅一体的地方，再里面有个用榻榻米做的房间（这个更像是中国的客厅）。进这个客厅要拖鞋。

在阳台之间有一道门，专门有一个警示，邻居在紧急情况下可以破这个门，这里是逃生的地方，请不要堆放物品。我感觉东京公寓对安全这一块做的十分好，一方面日本邻里之间十分注重各自的隐私，没有情况下不会打扰。但另外一个方面也为极端情况做了考量。让他们在紧急情况下可以避难逃生。

到了涩谷，很热闹，那个人行道4个红绿灯都变绿了之后，特别壮观，专门有很多人在附近建筑物的二楼去拍这个景色。涩谷也很干净。
专门有一个吸烟区，里面超多人吸烟。去忠犬八公的雕像拍了张照。

乌鸦很多。

学了日语：日本桥 (nihong bashi)

# 第三天
国立新美术馆，teamlab borderless
日本的美术馆博物馆真是十分多，大部分可以免费进去，然后里面如果有特殊的展览的话，就要付费购票。在美术馆发现老人十分多。我自己认为不太懂什么美术，之前去过一些美术馆也看不太懂，但是这个美术馆的画真的很好，要不是已经预定了teamlab borderless的票，真的可以在里面看一天。

teamlab borderless中文翻译过来叫“无象艺术空间”，是个十分特别的地方。里面主要是投影，但是最特别的是可以跟投影互动，里面的每一刻景象，都是游客一起参与进来构建的结果。每一刻景象都是不可重现的。

# 第四天
皇居外苑，国文书馆

皇居外苑是日本天皇居住的地方，但内圈不对外开放，只有皇居外苑是对外开放的，这个就是一个普通的公园。它最特殊的地方还是在樱田门了，这里是幕府大名，井伊直弼被刺杀的地方。

国文书馆里面的特别展是将日本在二战后期跟美国对抗的历史，主要介绍了神风敢死队，日本如何对美国舰队进行自杀袭击，还有美国如何占领硫磺岛，然后往东京投燃烧弹，最后劝降被忽视之后投下原子弹，最后麦克阿瑟如何将日本改造成民主国家的历史。虽然全是日文，但是借助了chatgpt，基本也都了解了。

下午就回去了，储蓄精力准备第二天去爬富士山。

# 整体感悟

不愧是民主国家，有一天回去在楼下就看到有通知，说地铁站前面有块空地要进行二次建设，然后要召开说明会，针对建设有3个方案，民众如果有建议可以预约，听说明会，然后给这一块的建设提意见。
垃圾分类是真的有在做垃圾分类，可燃垃圾，塑料袋，易拉罐，塑料瓶。全部都是要分开放的。
那边的人都超有礼貌，有不懂的地方问路，问厕所在哪里，都会领你走一段路，然后说怎么过去。
